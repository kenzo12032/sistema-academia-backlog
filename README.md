
# Sistema de Academia - Backlog

Projeto acadêmico desenvolvido para a prática de construção e organização de um backlog utilizando GitHub Issues e GitHub Projects.

## Objetivo

Criar um backlog rastreável para um sistema de gerenciamento de academia, utilizando User Stories, critérios de aceitação, labels, prioridades e organização das tarefas em um quadro Kanban.

## Domínio

Academia

## Perfis de Usuário

- Aluno
- Recepcionista
- Personal Trainer
- Administrador

## Funcionalidades

O backlog possui 8 User Stories:

1. Cadastro de aluno
2. Contratação de plano
3. Consulta do treino
4. Cadastro de treino
5. Agendamento de avaliação física
6. Controle de pagamentos
7. Consulta de alunos ativos
8. Cancelamento de plano

## Organização do Projeto

As tarefas foram organizadas utilizando GitHub Projects nas seguintes etapas:

- Backlog
- A fazer
- Em Desenvolvimento
- Em testes
- Concluído

## Tecnologias/Ferramentas

- GitHub
- GitHub Issues
- GitHub Projects
